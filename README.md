## 📱 О приложении

Приложение предоставляет доступ к каталогу персонажей из мультсериала "Rick and Morty" с использованием [The Rick and Morty API](https://rickandmortyapi.com/). Все данные кешируются локально и доступны без подключения к интернету.

## ✨ Возможности

- **🔍 Умный поиск** - поиск персонажей по имени с поддержкой оффлайн-режима
- **🎯 Расширенная фильтрация** - фильтры по статусу, виду, типу и полу
- **📱 Современный UI** - полностью написан на Jetpack Compose с Material Design 3
- **💾 Оффлайн-режим** - все данные кешируются и доступны без интернета
- **🔄 Pull-to-refresh** - обновление данных жестом
- **📖 Бесконечная прокрутка** - автоматическая подгрузка новых страниц
- **👤 Детальная информация** - подробные карточки персонажей

## 🛠 Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose, Material Design 3
- **Архитектура:** MVVM, StateFlow
- **Сеть:** Retrofit, OkHttp
- **База данных:** Room (SQLite)
- **Загрузка изображений:** Coil
- **API:** [The Rick and Morty API](https://rickandmortyapi.com/)
